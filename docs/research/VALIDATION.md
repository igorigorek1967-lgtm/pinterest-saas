## Исправления после независимого ревью

- Частотность с изменённым/неоднозначным форматом отклоняется; синтетические 1.5K, 1 200, 1,5 и повреждённые разделители не превращаются в ложные числа.
- SSE читается по событиям и завершает запрос сразу на совпавшем ID; открытый поток проверен синтетически.
- Logout отзывает сессию на сервере. Перезапуск сохраняет сессию, смена пароля отзывает её.
- Полная копия v2 восстанавливает задания, proxy и >5000 наблюдений в пустой БД, ошибки откатывают транзакцию.
- Поздний ответ или ошибка запроса не появляются после смены контекста поиска. Код проверен; интерактивный browser race ещё не подтверждён.
- Правильный пароль не блокируется общим счётчиком. Публичный вход требует проверенного rate limit / закрытого ingress; текущий 429 не является защитой перебора.

## Инфраструктурный preflight

Повторная проверка: после обновления страницы терминал Coolify заработал. `hostname -I` подтвердил, что эта панель относится к Beget, а не к целевому OnDash. Для размещения она не используется. Имеющиеся pending proxy changes не применялись.

OnDash доступен по SSH из Beget. Публичный ED25519 host key сверён с ранее подтверждённым отпечатком; проверка StrictHostKeyChecking не отключалась. Попытка входа с существующими ключами Beget получила `Permission denied (publickey)`. Временный файл с публичным host key удалён; новые ключи и доступы не создавались.

Кабинет OneDash доступен и подтвердил целевой заказ: Amsterdam, Crazy, Ubuntu 24, 4 vCPU / 8 GB, ONLINE. Открытие штатной VNC-консоли провайдера остановлено браузером с `ERR_CERT_AUTHORITY_INVALID`. Предупреждение не обходилось. Проверка диска, портов и доступа внутри самой VM не завершена; deployment не запускался.

Подготовлены `compose.research-pilot.yml` (только loopback, отдельный том) и `scripts/research/preflight.py` (только чтение). Preflight закрепляет локальный Docker socket и сверяет имя daemon с VM; сверяет hostname/IP/публичный host key, доступный диск системного и Docker-разделов, память, Docker/Compose, порт и коллизии контейнеров/томов/сетей с существующим пилотом, включая ресурсы без labels. Команды Compose закрепляют отдельное имя проекта и не читают .env. Неполные данные закрывают запуск. Секреты, сведения аккаунта и реальные адреса не включены в скрипт. Проверки условий preflight выполнены на синтетических данных; на OnDash ещё не выполнены.
