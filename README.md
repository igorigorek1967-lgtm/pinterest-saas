# Pinterest Research Workbench

Собственный модуль исследования Pinterest: ключи и источники по проектам, вход владельца, постоянные наблюдения и задания на контент.

- Поиск ключей, подсказки, категории и сведения о теме через Pinmetrica MCP.
- Импорт CSV/JSON с датами, метриками и защитой от повторов.
- Проверка географических совпадений: «Ейск» не принимается за «корейский».
- Серверное хранение SQLite и задания на проверку владельцу.
- Отдельный воспроизводимый REA-анализ публичных клиентских файлов в GitHub Actions.

## Запуск

Node.js 24.19.0+, npm. Настройка секретов и постоянного тома обязательна; без неё вход закрыт.

```bash
npm ci
npm test
npm run build
npm run start
```

Интерфейс — `/research`. Для размещения подготовлен Dockerfile.

- [Серверная настройка и работа владельца](docs/research/SERVER.md)
- [Закрытый пилот на OnDash](docs/research/PILOT.md)
- [Проверки и оставшиеся ограничения](docs/research/VALIDATION.md)
- [Выводы исследования](docs/research/FINDINGS.md)

Источник данных остаётся внешним. Доставка в OmniHub пока выполняется экспортом JSON; автоматическая доставка не объявляется успешной. Production-развёртывание требует отдельной проверки и независимого ревью.
